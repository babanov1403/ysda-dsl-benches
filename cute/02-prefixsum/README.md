# 02 — Prefix sum (пока не реализовано)

Следующая задача: inclusive prefix sum по последней оси contiguous FP32 `[rows, cols]`.
Эталон: `torch.cumsum(x.double(), dim=-1).float()`; допуски определяются отдельно
с учётом длины scan и порядка сложения, а не копируются из softmax.

Начать с одноблочного/однопрограммного scan для ограниченной длины строки.
Затем добавить отдельный вариант для длинных строк с межблочным переносом сумм.
Обязательные случаи: длина 1, неполный warp/block, случайные знакопеременные данные,
нули, константы, несколько строк. Зафиксировать семантику overflow и dtype.

Добавить `kernel.py` с `prepare(inputs, out) -> launch()`, общий контракт и тесты.
CUDA C++ исходник добавить в `cuda/CMakeLists.txt`. До этого задача отсутствует
в CLI: заглушка не должна попадать в бенчмарк как успешная реализация.
